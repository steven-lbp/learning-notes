# 图片来源与保存约定

本目录存放 OPD 笔记引用的图片，正文使用相对路径。流程图优先保留 SVG；截图和生成位图保存为 PNG、WebP、JPEG 等实际文件。文件名写清内容，移动主题时一起移动 Markdown 和图片目录。

This directory stores images used by the OPD notes, referenced through relative paths. Prefer SVG for diagrams and actual PNG, WebP, or JPEG files for screenshots and generated bitmaps. Use descriptive filenames, and move images together with their Markdown notes.
